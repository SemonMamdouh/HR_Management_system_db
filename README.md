# 📘 HR Management System Database

This project is a comprehensive **HR Management System Database**, built as part of my **ITI (Information Technology Institute) scholarship**, aiming to model and automate all core HR processes in a company through structured and advanced SQL design.

---

## 📌 Project Objective
To design and implement a scalable and efficient relational database that can manage:
- Employees & Departments
- Recruitment & Candidates
- Attendance & Payroll
- Training & Performance Evaluation
- Requests, Accounts & User Roles

---

## 📐 ERD & Schema Mapping

The database was designed using a clear **Entity Relationship Diagram (ERD)** and **schema mapping** to reflect real-world business needs.  
✔️ You can find the full diagrams in the `/diagrams` folder or view them in this repo.

---

## 🧠 Key Entities
- **Employee**: Stores employee details including supervisor, job title, and department.
- **Department**: Contains department info and manager relationships.
- **Project**: Tracks employee assignments to projects.
- **Candidate & Recruitment Process**: Handles job applications and interviews.
- **Attendance**: Records daily attendance and overtime.
- **Payroll**: Calculates net salaries including bonuses and deductions.
- **Training**: Tracks training sessions and participants.
- **Performance Evaluation**: Monitors employee productivity, teamwork, and evaluation scores.
- **Request**: Stores employee requests and statuses.
- **Account**: Manages login info and user roles.

---

## 🛠️ Advanced SQL Techniques Used

This system goes beyond basic CRUD operations — using advanced SQL for automation, analytics, and reporting:

- ✅ **Stored Procedures** – Automate HR processes (e.g., salary calculation, performance update)
- ✅ **Cursors** – Loop over employee records for sequential operations
- ✅ **User-Defined Functions** – Encapsulate reusable logic (e.g., calculate net salary)
- ✅ **Views** – Simplify access to complex joins for reports
- ✅ **MERGE Statements** – Synchronize and upsert employee data
- ✅ **Window Functions** – Rank, partition, and analyze employee performance, attendance trends, etc.

---

## 📈 Why This Database Matters
A strong HR database isn't just about storing data. It empowers companies to:
- Make data-driven HR decisions
- Track performance and training needs
- Automate payroll and attendance
- Support fair and informed hiring
